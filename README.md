Annotation UI for drug mechanism-of-action paths (11-tier rubric).

Everything runs in the browser. Progress is kept in `localStorage` and
exported as a JSON file; nothing is sent anywhere.

3 annotator bundle(s) in this build.

Stage 1 judges the path alone; stage 2 reveals the curated reference and asks
only how the two relate.
